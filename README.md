## Selected Work

- [**AlTur — Compiler & Virtual Machine in C**](https://github.com/ranjanmangla1/AlTur)  
  A bytecode compiler and stack-based virtual machine with functions, closures, classes, hash tables, and mark-and-sweep garbage collection.

- [**Event-Driven Data Collection Platform**](https://ranjanmangla.notion.site/Data-Colllector-5fe0e37cbb2a4d7abb5690f33bfd4a25)  
  A systems-design and implementation artifact for a queue-backed workflow with dedicated services, Kubernetes deployment, failure isolation, and retry/DLQ design.

- [**FitQuest**](https://github.com/ranjanmangla1/FitQuest)  
  A team-built pose-aware fitness product with workout routines, calorie tracking, and real-time webcam-based exercise feedback.

- [**Media Ingestion & HLS Transcoding Pipeline**](https://github.com/ranjanmangla1/adhyayan-migration)  
  A media-operations utility for ingesting remote video into S3-compatible storage and producing multi-rendition and HLS output with FFmpeg.

- [**Asynchronous Video-to-MP3 Service**](https://github.com/ranjanmangla1/ffmpeg-video-mp3-microservice)  
  A queue-backed media-processing prototype using Flask, RabbitMQ, MongoDB GridFS, Docker, and Kubernetes.
